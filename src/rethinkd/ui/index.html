Connect to Rethink Root

The daemon serves this page at 127.0.0.1:8777, but this browser has no token for it yet.

  1. Open a terminal on this machine.
  2. Run rethinkctl ui — it prints a fresh token.
  3. Paste the token below.
rethinkctl ui

The token is kept only in this browser's localStorage and sent to the daemon as the X-Auth-Token header. Rotate it any time with rethinkctl token.
